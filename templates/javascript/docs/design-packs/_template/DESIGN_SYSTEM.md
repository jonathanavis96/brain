# DESIGN_SYSTEM

## Purpose

Canonical design tokens and visual language.

## Status

**Template stub** — fill in for your project.

## Tokens (define your scales)

- Color palette (background/surface/text/semantic colors)
- Typography scale (font families, sizes, line heights, weights)
- Spacing scale (e.g. `space-1..space-10`)
- Radii (e.g. `radius-sm/md/lg`)
- Shadows (e.g. `shadow-sm/md/lg`)

## Rules

- All UI values must reference tokens (no hardcoded values in components).
- If a needed token does not exist, propose it and update this file before implementation.
